라이선스 사용 안내

앱을 쓰려는 분과, 발급하는 분 모두를 위한 안내입니다.

앱을 쓰시려면

  1. 앱을 실행하면 라이선스 화면이 뜹니다. [라이선스 요청하기] 를 누르세요. 머신 ID 가 채워진 요청 폼이 열립니다.
  2. 이름과 용도를 적고 제출하면 됩니다.
  3. 승인되면 앱이 알아서 활성화됩니다. 라이선스 화면을 켜둔 채 기다리세요 (최대 5분).

라이선스는 그 PC 에서만 유효합니다. 다른 PC 로 옮기거나 남에게 넘겨줄 수 없고, OS 를 다시 설치하면 재발급이 필요합니다.

발급하시려면

요청이 오면 GitHub 알림 메일이 옵니다. 그 메일에 답장하거나 이슈에 댓글을 다세요.

/approve         30일 발급
/approve 90      90일 발급
/autorenew 30    만료 3일 전마다 30일씩 자동 연장 (이후 손 안 대도 됨)
/autorenew off   자동 갱신 끄기
/revoke          이 PC 차단
/deny            거절

나머지는 GitHub Actions 가 합니다 — 서명, 발급, 커밋, 이슈 닫기까지. 만료가 다가오면 매일 아침 알림 이슈가 열리고, 자동 갱신을 켜둔 것은 알림 없이 알아서 연장됩니다.
