라이선스 안내

앱을 쓰시는 분과, 발급하는 분 모두를 위한 문서입니다.

앱을 쓰시려면

  1. 앱을 실행하면 라이선스 화면이 뜹니다. [라이선스 요청하기] 를 누르면 머신 ID 가 채워진 요청 폼이 열립니다.
  2. 이름과 용도를 적고 제출합니다.
  3. 승인되면 앱이 알아서 활성화됩니다. 그 화면을 켜둔 채 기다리세요 — 반영까지 최대 5분입니다.

라이선스는 그 PC 에서만 유효합니다. 다른 PC 로 옮기거나 남에게 넘겨줄 수 없고, 운영체제를 다시 설치하면 머신 ID 가 바뀌어 재발급이 필요합니다.

발급하시려면

요청이 오면 알림 메일이 옵니다. 그 메일에 답장하거나 이슈에 댓글을 다세요.

/approve         30일 발급
/approve 90      90일 발급
/autorenew 30    만료 3일 전마다 30일씩 자동 연장
/autorenew off   자동 갱신 끄기
/revoke          이 PC 차단
/deny            거절

나머지는 GitHub Actions 가 합니다 — 서명, 발급, 커밋, 이슈 닫기까지. 저장소에 쓰기 권한이 있는 사람이 요청하면 댓글 없이 바로 발급됩니다.

자주 나오는 상황

화면에 나오는 말 원인 조치
다른 PC 앞으로 발급된 것입니다 PC 교체 · OS 재설치 새 머신 ID 로 다시 요청

정책을 확인하지 못했습니다 인터넷이 막혀 있음 연결 확인 후 다시 실행
시스템 시계가 과거로… PC 시간이 틀림 시간 동기화 후 재실행
